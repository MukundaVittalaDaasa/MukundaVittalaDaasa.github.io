Types of pieces (the buttons on the website)

One per line as Name | layout | Button name | Kannada subtitle. Layouts: kriti (pallavi, anupallavi, charanas), verses (no pallavi, for ugabhoga), article (blog writing). Each type becomes its own button on the website. Example: Suladi | verses | Suladis | ಸುಳಾದಿ.

Set up once (so Publish and Upload work)
  1. Open github.com/settings/tokens/new (choose Tokens (classic)).
  2. Name it kriti-editor and pick the longest expiry.
  3. Tick only public_repo, then tap Generate token and copy it.
  4. Paste it below, tap Save connection, then Test connection.
