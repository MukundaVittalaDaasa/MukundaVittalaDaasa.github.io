Connect to GitHub (once)
  1. Open github.com/settings/tokens/new and choose Tokens (classic).
  2. Name it kriti-editor, pick the longest expiry, tick only public_repo, then Generate and copy the token.
  3. Paste it below and press Save connection, then Test connection.
